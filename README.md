# Harsh Kumar Sinha — Portfolio v2

Premium animated portfolio with dark/light theme toggle.
Built with React + Vite + TailwindCSS + Framer Motion.

## Quick Start

```bash
npm install
npm run dev
```
Open http://localhost:5173

## Theme Toggle
Click 🌙/☀️ in the navbar to switch dark ↔ light theme.
Your choice is saved automatically.

## Customize Content
Edit src/utils/data.js — all content (bio, projects, skills, links) is there.

## Replace Photo
Drop your photo as public/harsh-photo.jpg

## Build & Deploy
```bash
npm run build   # creates dist/
npx vercel      # deploy to Vercel
```
